Hint 1 Think about the approach
Questions to guide you:
• What data structure fits this problem? (array, stack, map, tree, graph?)
• Have you seen a similar pattern before? (two pointers, sliding window, binary search?)
• What's the brute force? Can you optimize from there?
• Try writing pseudocode before real code.
Hint 2 Narrow down the technique
Dig deeper:
• If the answer is monotonic, consider binary search on the answer.
• If you need range queries, think prefix sums or segment tree.
• If there are dependencies, think topological sort or DP.
• If constraints are small (N ≤ 20), try bitmask/backtracking.
• Read the constraints carefully — they hint at the expected complexity.
